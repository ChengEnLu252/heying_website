# 鶴英新北芭蕾舞團 官方網站

**He Ying New Taipei Ballet — Official Website**

成立於 2001 年，鶴英新北芭蕾舞團是立案於新北市板橋區的古典芭蕾舞團，致力於古典芭蕾教育與推廣。

🌐 **網站連結：** [heyingballet.netlify.app](https://heyingballet.netlify.app)

---

## 網站特色

- 單頁式響應式設計（RWD），支援桌機與手機
- 日夜模式切換（Dark / Light Theme）
- 中英文雙語切換
- 粒子網格背景與滑鼠跟隨光暈
- 自訂游標（桌面版）
- 膠片質感 Grain Overlay
- 頁面載入動畫與滾動漸現動畫
- 經典劇碼跑馬燈
- 數字計數動畫
- 演出紀錄橫向滑動卡片
- 照片集錦 Masonry 網格 + Lightbox 放大檢視
- 學員好評無限滾動
- FAQ 手風琴展開收合
- LINE 預約按鈕整合

## 部署方式

本網站使用 [Netlify](https://www.netlify.com/) 部署：

1. 將整個專案資料夾拖曳至 Netlify 的 Deploy 頁面
2. 自動部署完成，取得固定網址
3. 後續更新只需在同一站點重新拖曳上傳

## 技術

- 純 HTML / CSS / JavaScript，無框架依賴
- Google Fonts：Noto Serif TC、Cormorant Garamond、Playfair Display
- Canvas 粒子動畫
- CSS 自訂屬性實現主題切換
- IntersectionObserver 實現滾動動畫
